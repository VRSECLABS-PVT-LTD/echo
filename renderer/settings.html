Sounds
Little chimes for reminders and bill alerts, and a soft "bloop" when Echo replies. Off = notifications use your system's default sound.

Privacy

Local-only mode
Blocks every request that would leave your local network, including API integrations on internet hosts. Recommended.
Keep chat history between sessions
Off = Echo forgets the conversation when you quit. Reminders, expenses and memories are always kept.

Integrations

Home Assistant (local)

Control lights, plugs and more. Echo talks to Home Assistant on your local network only, and asks before every action.

API integrations

Import an OpenAPI / Swagger schema (JSON or YAML) and Echo can call that API for you. Tokens are encrypted and never shown again. Requests only go to the host you set, and anything that changes data (POST / PUT / PATCH / DELETE) asks for approval first. APIs on internet hosts need local-only mode turned off.

About

Echo by VRSecLabs

Echo is a private AI assistant that runs entirely on your computer. It was built by VRSecLabs, a security lab that makes privacy-first tools.

  • On-device. The AI model runs locally. Your words are never sent to a cloud service.
  • Encrypted. All your data is encrypted at rest with a key held by your operating system's keychain.
  • Transparent. No telemetry, no analytics, no accounts. Every outside connection is shown in the network log.
  • Open source. Licensed under GPL-3.0. Anyone can read, audit and improve the code.
